## I. 管理画面の起動方法

```sh
python3 -m violet_office.web init
python3 -m violet_office.web serve --open-browser
```

Windowsはpython3を `py -3` に置換。初回設定後、デスクトップ用起動スクリプトも利用可能。ブラウザのアドレス欄は `http://127.0.0.1:8765/` 。PC内限定、外部公開不可。詳細はrunbook.md。

バックアップ/復旧は以下。既存ファイルは上書きしない。

```sh
python3 -m violet_office.ops health --db var/office.sqlite3
python3 -m violet_office.ops backup --db var/office.sqlite3 --output var/backups/NEW.sqlite3
python3 -m violet_office.ops restore --db var/backups/NEW.sqlite3 --output var/recovery/NEW-restore.sqlite3
```
