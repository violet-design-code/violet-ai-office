# 対外発信の法令・規約確認手順

本書は確認工程であり、法律相談・法令適合の保証ではない。実際の公式資料の取得・最新版照合・専門家判断は未実施。未確認の効能、収入、成功実績、紹介報酬や特典を原稿に追加しない。

## 確認から承認まで

1. 正規資料を入手し、文書名・版/施行日・参照日・該当箇所・確認者・結論・必要な専門家照会を記録する。
2. 対象の原稿ID・版・ハッシュを固定する。原稿の表現が根拠に対応するか確認し、根拠のない記述を削除/修正した新しい版を作成する。
3. 別担当が表現・事実を確認し、AI28のルール結果と未確認項目を確認する。ルールの合格を法律判断と扱わない。
4. 管理画面の承認センターで、実際に確認した項目だけ「確認を記録」。根拠欄に上記参照情報を書く。秘密値や顧客の個人情報を記載しない。
5. 全項目の確認が揃ってから代表が承認する。LINE/SNS規約を含む現行の確認項目が欠ける旧監査は、新しい発信には使用できない。
6. 原稿を修正したら新しい版を監査し直す。過去の承認を流用しない。
7. 承認だけで送信しない。実サービス接続と送信直前の同意/停止/予約/原稿版/送信承認の確認が別途必要。現在は実送信経路自体がない。

法令適合性の解釈が必要なら専門家に照会し、回答前に公開しない。確認欄を埋めるために未実施の確認を登録しない。テストの合成確認記録は本番承認へ転用しない。
