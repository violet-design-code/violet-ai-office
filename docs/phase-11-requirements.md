# 第11段階の正式要求・出典

出典：2026年10月26日（日本時間）、代表から受領した「第11段階 AI新規事業開発・市場調査・収益シミュレーションシステム」の開発指示と、その後の対象事業・未設定目標に関する回答。

本書は今回の正式要求を整理したものです。昨日の会話の逐語原文ではなく、未確認の第12段階以降を補完する資料でもありません。

## 目的

VIOLETの自社事業について、代表が方向性を決め、既存28役で市場・競合・顧客・価格・財務・集客・販売準備・リスク・検証計画を分担する。AI OFFICE自体の販売を目的にしない。収益保証をせず、実績と予測を区別する。

## 代表の追加回答

- 最初の1事業に限定せず、セルフホワイトニング、スマホ教室、鏡のウロコ取り出張サービス、美容・健康関連等と新規候補を比較できる設計
- 予算・稼働時間・希望月商・希望利益は未設定。代表が後から画面で入力・変更する
- 市場調査、競合分析、収益シミュレーション、優先順位の提案、実行計画作成をAIの担当範囲とする
- 試算は仮の数値であることを明示し、実績として登録しない
- 外部送信・課金・契約・公開は実施せず、別途代表承認を必須とする

## 今回の機能要求

1. 業種・地域・対象・予算・時間・希望月商/利益・資産を持つアイデアの登録、編集、比較、保留、却下、承認
2. 需要、顧客課題、競合、差別化、価格帯、地域性、集客経路の出典/調査日/確信度/未確認事項の記録。未接続を調査済みとしない
3. 入力前提から初期費用、固定/変動費、売上、粗利益、営業利益、損益分岐、単純回収期間を計算。悲観/標準/楽観の前提を編集し、式と予測ラベルを表示
4. 既存28役を増員/権限変更せず、担当・理由・入力・出力・進捗・レビュー担当を表示
5. 概要、対象、価値、競合、強み、価格、経費、試算、集客、営業導線、実施手順、リスク、KPI、撤退基準を含む提案書。根拠不足は要調査
6. 代表承認済み提案のみ7/30/90日内部計画と担当タスクを作成。予算、KPI、実績、改善案を管理。外部実行の承認と分離
7. PC/スマートフォン向けの候補・調査・予測・投資・リスク・承認・進捗・実績画面と事業別権限/監査

ベネシード関連は公式情報・契約条件・費用・法的分類を確認対象にし、根拠なくネットワークビジネスではないと断定しない。医療効果・収益保証・適法性を断定しない。個人情報を外部AI/未承認サービスへ送信しない。既存機能を保護し、本番DBの初期化・削除・無断移行をしない。
