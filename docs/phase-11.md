## 実装済み

### 候補・調査・提案

複数の候補を登録/編集/保留/却下/アイデア承認できる。初期値の予算・利用時間・希望月商/利益はNULL。方向性/資産を入力でき、既存の6事業のどれかへ代表が明示選択した場合だけ関連付ける。未紐付けは代表専用。登録後の所属変更によるデータ漏えいを避け、所属の自動変更は提供しない。

資料は7分類（需要/顧客課題/競合/差別化/価格帯/地域性/集客経路）。内容、出典、実際の調査日、入力者の確信度、仮説/未確認/代表の資料確認、未確認事項を保存する。代表確認には出典と過去/当日の調査日が必要。外部URLを取得せず、検索/スクレイピングを実行しない。資料の撤回と履歴保存もできる。代表の資料確認は独立した事実検証や現在の有効性の保証ではない。

提案書は概要・対象・価値・競合資料・強み/資産・価格・経費/3試算・集客/営業導線・内部準備手順・リスク・計測/撤退条件を含む固定構造。根拠不足は要調査。危険な勧誘/指示文を機械的に検出し、代表のチェックなしに承認しない。法令適合や医療効果、収入、ベネシードの法的分類を自動で断定しない。

比較は代表だけが2〜10候補を選択する。3シナリオが入力済み、7分類の代表確認資料あり、予算/時間条件が明示され標準が条件内・営業利益が正の場合だけ、選択した比較軸（確認資料/標準予測利益）で暫定順位を付ける。条件不足は順位なし。予測は同じ月次/円建てで比較し、実際の成約可能性や成功確率とは呼ばない。比較後に入力が変わった場合は要再比較を表示する。

### 収益試算の定義

数値は入力者が仮定と根拠を明示する。悲観/標準/楽観の倍率や客数を勝手に生成しない。8項目が揃うまで未算定。Decimalで計算し、表示は小数2桁、損益分岐件数は切り上げる。

| 指標 | 月次モデルの式 |
| --- | --- |
| 期待成約件数 | 見込み客数 × 成約率 / 100（小数の期待値） |
| 売上 | 期待成約件数 × 単価 |
| 変動費 | 期待成約件数 × 1件あたり変動費 |
| 粗利益 | 売上 − 変動費 |
| 営業利益 | 粗利益 − 月間固定費 |
| 損益分岐件数 | ceil(固定費 / (単価 − 1件あたり変動費)) |
| 単純回収期間 | 初期費用 / 月次営業利益（正の場合） |
| 必要作業時間 | 期待成約件数 × 1件あたり時間 |

限界利益が非正なら損益分岐を未算定にする。営業利益が非正なら回収期間は未算定。成約率0で割らず、必要リード数も未算定とする。時間超過は警告し、客数を黙って減らさない。初期費用は月次営業利益から毎月一括控除せず、回収期間の対象として分離する。

税/金利/借入/減価償却/季節性/運転資金等は未計算。単純回収はキャッシュフロー分析ではなく、一定の月次利益が継続する仮定。投資助言・収益保証ではない。入力範囲は非負・最大10億・小数4桁、NaN/Infinity/負数/未知キーを拒否する。

### 承認済みの内部計画と実績

アイデア承認と提案承認を分ける。代表が根拠/仮説/未確認事項を確認した提案だけから7/30/90日計画を作る。計画ごとに検証予算円、API予算USD、KPI、撤退条件、開始日を設定する。KPI/撤退の数値は未指定なら未設定。外部送信・課金・契約・公開は別承認が必要で、現段階の外部実行経路はない。

各計画は最大7工程を既存Storeの内部タスクへ割当。共通成果物は参照メタデータのみで、私的な候補や仮説は権限付きテーブルに保存する。工程の実行は固定チェックリストの保存であり、実市場調査やLLMの実務完了ではない。成果物はレビュー待ち。各タスクは既存の最大3試行/60秒期限/予算制御を維持し、自動ワーカーや無限実行は追加しない。

重複生成/同時実行を防ぎ、既存の共通タスク画面や事業実行画面から別経路で動かせない。リンク済み計画は事業予算も、未紐付けは候補の計画API予算も検証する。API上限初期値0は無料内部処理だけ。検証経費の実測申告が期間内の円予算に到達した場合も停止する。新規の有料APIは使わない。

アイデア/資料/仮定変更で旧提案をstale、内部計画を停止し、再生成/再承認を要求する。本文や計画条件のハッシュと承認記録も照合する。手動停止/安全な再開が可能。復元コピーでは提案と改善レビューを再承認待ち、計画を停止し、既存の緊急停止/セッション失効も維持する。

実績は別テーブルに日付/指標/値/実測申告・推定・モック/根拠/改訂履歴を記録する。試算から実績や既存の売上台帳へ自動転記しない。記録済み合計は部分計測で、未記録を0にしない。月次予測と任意日数の検証実績を直接比較して達成率を捏造しない。計測不足・期間未確認等から改善候補を生成し、別の代表承認待ちにする。承認しても自動適用しない。
